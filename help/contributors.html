Gelegentlich beitragen

Eine Ressource vorschlagen oder auf einen Fehler hinweisen. Ein Google-Konto ist dafür nicht nötig.

Eine Ressource vorschlagen

  1. Formular öffnen

    Im Katalog auf Ressource vorschlagen klicken. Für einen öffentlichen Vorschlag bleibt der persönliche Einladungscode leer.

  2. Die Ressource beschreiben

    Titel, Link und eine kurze Beschreibung auf Deutsch oder Englisch eintragen. Die zweite Beschreibung ist optional. Eine Adresse wie example.org wird als HTTPS-Link ergänzt.

  3. Passend einordnen

    Fach, Schwierigkeit, Sprache der Ressource und Format wählen; den Bildungsbereich ergänzen. Eine Institution auswählen oder, falls sie fehlt, ihren Namen und optional ihre Website angeben.

  4. Absenden

    Die Redaktion erhält den Vorschlag zur Prüfung. Nach der Freigabe wird er automatisch auf der Website veröffentlicht. Ein freiwilliger Rückfragekontakt bleibt privat.

Ein Problem oder eine Korrektur melden

  1. Flagge am Eintrag anklicken

    Die Flagge auf der Ressourcenkarte oder Problem melden in den Details öffnet ein kurzes Meldeformular. Die Ressource ist bereits eingetragen.

  2. Den Hinweis beschreiben

    Grund auswählen: defekter Link, falsche Angaben, veralteter Inhalt, Qualität oder etwas anderes. Kurz erklären, was geändert werden sollte; einen besseren Link oder Beleg gern ergänzen.

  3. Absenden

    Die Redaktion prüft den Hinweis. Eine Meldung ändert oder entfernt den Eintrag nicht automatisch.

Keine Institution oder Betreuung bekannt? Die Zuordnung offenlassen. Name und Zugehörigkeit sollten sich aus der Ressource belegen lassen.

STEP BY STEP

Occasional contributors

Suggest a resource or point out a problem. You do not need a Google account.

Suggest a resource

  1. Open the form

    Choose Suggest a resource in the catalogue. Leave the personal invitation code empty for a public suggestion.

  2. Describe the resource

    Add a title, link and short description in German or English. The other description is optional. An address such as example.org receives an HTTPS prefix.

  3. Choose suitable categories

    Select the subject, difficulty, resource language and format; add the educational context. Choose an institution or, if it is missing, enter its name and optional website.

  4. Submit

    The editorial team receives the suggestion for review. Once approved, it is published automatically. Any optional contact information stays private.

Report a problem or suggest a correction

  1. Choose the flag on the entry

    The flag on the resource card or Report a problem in its details opens a short reporting form. The resource is already filled in.

  2. Explain what needs attention

    Choose a reason: broken link, incorrect information, outdated material, quality or another issue. Briefly explain the problem; add a replacement link or supporting source when useful.

  3. Submit

    The editorial team reviews the report. Reporting an entry does not automatically change or remove it.

Institution or maintainer unknown? Leave the attribution empty. Names and affiliations should be supported by the resource itself.
