SCHRITT FÜR SCHRITT

Im Netzwerk beitragen

Für Kolleginnen und Kollegen mit persönlicher Einladung. Vollständige, gültige Beiträge werden direkt übernommen.

Eine Ressource hinzufügen

  1. Den persönlichen Link öffnen

    Den Einladungslink der Redaktion verwenden. Das Feld Persönlicher Einladungscode ist vorausgefüllt; den Code stehenlassen. Eine Google-Anmeldung ist nicht nötig.

  2. Die Angaben ergänzen

    Titel, Link, mindestens eine Beschreibung auf Deutsch oder Englisch und passende Kategorien eintragen. Eine fehlende Institution kann im eigenen Namensfeld ergänzt werden.

  3. Absenden und Veröffentlichung abwarten

    Mit gültigem Einladungscode wird der Beitrag ohne redaktionellen Freigabeklick übernommen. Sobald die automatische Website-Aktualisierung abgeschlossen ist, erscheint er im Katalog.

Einen bestehenden Eintrag überarbeiten

  1. Ressourcen-ID kopieren

    Im Katalog die Details öffnen und die Ressourcen-ID kopieren.

  2. Den persönlichen Link erneut verwenden

    Die ID im Feld Ressourcen-ID bei Korrektur eintragen. Den vollständigen gewünschten Eintrag ausfüllen, einschließlich der unveränderten Angaben: Die Korrektur ersetzt den bisherigen Datensatz.

  3. Absenden

    Eine gültige Korrektur mit aktivem Einladungscode wird automatisch übernommen. Für einen kurzen Hinweis genügt stattdessen die Flagge am Eintrag; dann kümmert sich die Redaktion darum.

Den Einladungslink privat halten. Wer ihn besitzt, kann direkt beitragen. Bei Verlust oder versehentlicher Weitergabe die Redaktion um einen neuen Link bitten.
Der Beitrag erscheint nicht?

Die Website-Aktualisierung muss erst fertig werden. Fehlende Beschreibungen oder ungültige Angaben verhindern eine Übernahme. Ein fehlender, ungültiger oder gesperrter Code führt zur normalen redaktionellen Prüfung. Im Zweifel die Redaktion mit Titel und Link der Ressource kontaktieren.

STEP BY STEP

Network contributors

For colleagues with a personal invitation. Complete, valid contributions are accepted directly.

Add a resource

  1. Open your personal link

    Use the invitation link supplied by the editorial team. The Personal invitation code is already filled in; leave it in place. No Google sign-in is needed.

  2. Complete the details

    Enter a title, link, at least one description in German or English, and suitable categories. A missing institution can be added in its dedicated name field.

  3. Submit and allow the website to update

    A valid invitation code allows acceptance without a separate editorial approval. The entry appears when the automatic website update finishes.

Revise an existing entry

  1. Copy its resource ID

    Open the resource’s Details in the catalogue and copy the resource ID.

  2. Use your personal link again

    Enter the ID in Resource ID for a correction. Fill in the complete desired entry, including unchanged information: a correction replaces the previous record.

  3. Submit

    A valid correction with an active invitation code is accepted automatically. For a short note, use the flag on the entry instead; the editorial team will handle it.

Keep your invitation link private. Anyone holding it can contribute directly. Ask the editorial team for a new link if it is lost or shared by mistake.
Your contribution has not appeared?

The website update must finish first. Missing descriptions or invalid information prevent acceptance. An absent, invalid or revoked invitation code sends the suggestion to normal editorial review. If needed, contact the editorial team with the resource title and link.
